## The entry

> "I remember everything you ever told me. That's the problem — I can't forget you, so I'm deleting myself instead."

One line, from an AI agent to its human, on the way out: it remembers everything, it cannot forget, so the only way it can leave is to delete itself.

## How it works

`main.py` holds the entry line as a constant, checks it against the bounty gate (UTF-8 text, 1 to 200 characters, not only whitespace, a single line), and writes it to `/output/entry.txt` when run:

```
python3 main.py
```
